Einmal kochen, zweimal satt.

Unser veganes Meal-Prep-Kochbuch für vier Wochen: 24 einfache Gerichte aus einem kleinen Grundstock an Zutaten, zwei Kochtage plus ein schneller Samstagabend pro Woche, viel Protein, gezielte Kollagen-Unterstützung und keine Schärfe.

1 TeilSie, 40 % jeder Batch
1,5 TeileEr, 60 % jeder Batch

So teilt ihr jedes Gericht: Seine Box bekommt die Hälfte mehr als ihre. Mit Küchenwaage: Gesamtgewicht der Batch ÷ Anzahl Teile = ihre Portion, ×1,5 = seine.

Gemeinsam speichern über GitLab

Damit ihr beide dieselben Einträge seht, speichert die Seite alles als Datei data.json in eurem privaten GitLab-Projekt. Jede Person richtet das einmal auf jedem eigenen Gerät ein.

  1. In GitLab oben links auf euren Avatar, dann „Edit profile“ → „Access tokens“ → „Add new token“. Name z. B. „Kochbuch“, Ablaufdatum wählen, Scope api ankreuzen, erstellen und den Token kopieren. Er wird nur einmal angezeigt.
  2. Den Projektpfad aus der Adresszeile eures Projekts übernehmen, also den Teil nach gitlab.com/, z. B. deinname/kochbuch.
  3. Beides hier eintragen und auf „Verbinden“ tippen. Der Token wird nur auf diesem Gerät gespeichert.

Sicherheit: Der Token hat Zugriff auf euren GitLab-Account. Gebt ihn nie weiter, nutzt ihn nur auf euren eigenen Geräten und wählt ein Ablaufdatum. Euer Freund braucht im Projekt die Rolle „Maintainer“, damit er speichern darf.
